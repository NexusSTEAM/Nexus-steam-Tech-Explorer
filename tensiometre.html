Le tensiomètre

Description

Un tensiomètre, ou sphygmomanomètre, est un appareil médical qui sert à mesurer la pression du sang dans les artères.

Fonctionnement

Il est formé d’un brassard que l’on place autour du bras ou du poignet pour le gonfler, et d’un écran ou d’un cadran qui affiche les résultats.

Les deux types de tensiomètres

  • Modèle électronique : il se gonfle tout seul grâce à une pile et affiche directement les chiffres sur un écran digital.
  • Modèle manuel : il demande une poire pour gonfler l’air et un stéthoscope. Le médecin écoute les bruits du cœur pour trouver la valeur.

Ce que les chiffres veulent dire

  • SYS : pression systolique, lorsque le cœur se contracte.
  • DIA : pression diastolique, lorsque le cœur se repose entre deux battements.
  • PUL : nombre de battements du cœur par minute.
